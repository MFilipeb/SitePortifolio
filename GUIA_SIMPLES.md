# 🎨 Guia Simples do Projeto (Para Crianças e Gênios)

Olá! Este projeto é como um **álbum de figurinhas digital**. Siga os passos abaixo e você será um mestre!

## 1. O que é o quê? 📂
*   **Pasta `app`**: É onde fica a "mágica" do site. Se quiser mudar o que aparece na tela, é aqui.
*   **Pasta `public`**: É a sua caixa de fotos. Coloque suas fotos aqui para usá-las no site.
*   **Pasta `prisma`**: É o "cérebro" que guarda seus links.

## 2. Como Mudar as Coisas? ✏️
Você não precisa mexer no código para mudar o site!
1.  Vá para `seu-site.com/admin` (ou `localhost:3000/admin` se estiver no computador).
2.  Lá você pode trocar as cores, o nome e os links. É como colorir um desenho!

## 3. Como Ver o Site no Computador? 💻
Se você quer ver o site enquanto mexe nele:
1.  Abra o "Terminal" (a telinha preta).
2.  Digite: `npm run dev`
3.  Abra o navegador e digite: `localhost:3000`

## 4. Dica de Ouro! 🌟
Se você estragar algo, não chore! O computador é seu amigo. Basta ler as mensagens na tela ou perguntar para o seu ajudante (eu!).
