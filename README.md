# 🚀 Projeto Emprego - Portfólio de Links

Este é um projeto estilo "Linktree" personalizado, feito com **Next.js** e **Prisma**. Ele é bonito, rápido e muito fácil de usar!

## 📦 O que tem dentro?
- **Site Principal**: Onde as pessoas veem seus links.
- **Painel ADM**: Onde você muda tudo sem precisar programar.
- **Banco de Dados**: Guarda suas informações com segurança.

## 🛠️ Como começar
1. Instale tudo: `npm install`
2. Prepare o banco: `npx prisma db push`
3. Ligue o site: `npm run dev`

## 📂 Organização
- `app/`: O coração do site.
- `app/components/`: Peças pequenas (como botões e ícones).
- `lib/`: Ferramentas que ajudam o site a funcionar.
